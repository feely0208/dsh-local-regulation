# 规则依据（逐条对照官方原文要点）

> 判据只做可静态检测的部分，不扩写、不引申。条款号与通过/施行日期以官方公布文本为准。

## 上海市数据条例

- **通过 / 施行**：2021-11-25 通过，2022-01-01 施行
- **第二十三条**（第三款为核心）：公共场所的图像采集、身份识别设备须设置显著标识，
  不得作为出入该场所 / 区域的唯一验证方式。
- 对应规则：`LR-SH-23` —— 项目使用人脸识别 / 图像采集能力，但全项目找不到显著标识、
  图像采集区域、人工核验 / 刷卡通行等替代验证方式的说明。

## 深圳经济特区数据条例

- **通过 / 施行**：2021-06-29 通过，2022-01-01 施行

| 条款 | 原文要点 | 对应规则 |
|---|---|---|
| 第二十六条 | 向他人提供个人数据的，应当先去标识化，使人无法识别特定自然人 | `LR-SZ-26` |
| 第二十九条 | 对自然人进行用户画像的，应当向其明示用户画像的具体用途和主要规则 | `LR-SZ-29` |
| 第七十三条 | 处理敏感个人数据或者重要数据的，应当设立数据安全管理机构、明确数据安全管理责任人 | `LR-SZ-73` |
| 第七十五条 | 对数据处理全流程进行记录，保障数据来源合法以及处理全流程清晰、可追溯 | `LR-SZ-75` |
| 第七十九条 | 共享、开放数据应当建立数据共享开放安全管理制度，建立和完善对外数据接口安全管理机制 | `LR-SZ-79` |
| 第八十条 | 应当建立数据销毁规程，对需要销毁的数据实施有效销毁 | `LR-SZ-80` |

## 判据的边界

- 规则是**文本存在性检查**：找到关键词只说明仓库里写到了，不说明实际执行到位；
  没找到也只说明仓库里没有，不说明公司没做。
- 每条规则只覆盖上表列出的那一条要求，不代表整部条例的全部义务。
- 本插件不判断实际运营地，适用范围需人工确认（见 `docs/适用范围.md`）。
